Privacy policy

This policy describes the personal OAuth application named rclone, maintained by jameslilzs, and this public information website.

Purpose and data accessed

The connection is used by its owner to manage their own Google Drive files from a privately managed server. It accesses file contents and metadata such as names, identifiers, sizes and modification times to list, read, upload, update, rename and delete files.

The configured mount targets the Diss folder. The granted https://www.googleapis.com/auth/drive scope is broader and allows access to other Drive files. The folder selection is an operational setting, not an authorization boundary.

How data is used and stored

File data is transferred between Google Drive and the owner's server to perform requested file operations. Read and write caches may store file contents on the server. Files that are separately copied or downloaded may also remain there.

OAuth access and refresh tokens and client configuration are stored in the owner's rclone configuration on the server. A computer used to complete authorization may also retain configuration if it was saved there. The connection uses tokens rather than storing the Google account password.

Operational logs may contain file paths, metadata and error details. Tokens, private file contents and the rclone configuration are not part of this public information repository.

Sharing and service providers

This personal connection does not sell file data or use it for advertising. It does not intentionally publish Drive files or transmit them to unrelated services. Google processes data as the Drive provider, and the server provider supplies the infrastructure on which local files, caches and configuration reside.

This website is hosted by GitHub Pages. Visiting it does not grant access to Google Drive or send Drive files to GitHub. The pages contain no application analytics, third-party scripts, forms or application cookies. GitHub may process visitor information such as IP addresses and request logs under its privacy statement.

Retention and deletion

Drive files remain in the owner's account until the owner changes or deletes them. Local cache retention depends on rclone's cache settings and whether files are open or awaiting upload; cache limits do not guarantee immediate deletion. Downloaded copies, logs and saved credentials remain until the owner removes them or their configured retention rules apply.

To remove local connection data, first allow pending uploads to finish and stop the mount, then remove the saved rclone connection, its cache, relevant logs and any separately downloaded copies. Removing local connection data does not itself delete files from Google Drive.

Control and revocation

The owner can revoke this application's access through Google Account connections. Revocation prevents further authorized API access but does not erase files or credentials already stored locally. The owner controls file deletion in Drive and on their server separately.

Contact and updates

For general questions or corrections, contact the maintainer through the repository issue tracker. Issues are public; do not post credentials, tokens or private file contents. This policy should be updated when the connection's data practices change; the effective date above identifies the current version.
