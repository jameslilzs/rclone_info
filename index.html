Application information

A personal connection
to Google Drive.

This OAuth application, named rclone, lets its owner use the rclone command-line tool to access their Google Drive files from a privately managed server.

What it does

The connection mounts the owner's selected Diss folder as a directory on their server. It supports listing, reading, uploading, editing, renaming and deleting files. Changes made through the mount affect the corresponding files in Google Drive.

Access and authorization

The owner signs in through Google's authorization page and grants access. The application requests the https://www.googleapis.com/auth/drive scope, which permits access to Drive files beyond the selected folder. Selecting a folder for the mount limits the configured operation; it does not narrow the OAuth permission.

OAuth tokens allow the connection to work without giving rclone the Google account password. Access can be revoked in the owner's Google Account connections.

Who operates it

This is a personal configuration maintained by jameslilzs. It is not offered as a public file-storage service, and this website does not provide a sign-in or file-upload feature.

The connection uses the independent open-source rclone project. This information site is not the official rclone website and is not operated by Google.

Privacy and contact

Read the privacy policy for details about file access, caching, retention and revocation. General questions can be raised in the information repository. Do not include tokens or private file contents in public issues.
